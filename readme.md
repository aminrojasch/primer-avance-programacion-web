

 QuestPass CR — Plataforma de Experiencias y Eventos

 📌 Descripción del Proyecto
QuestPass CR es un proyecto académico de desarrollo web creado con HTML5 y CSS. Su objetivo es representar una plataforma para consultar experiencias temáticas y gestionar visualmente solicitudes de reserva.

Contenido del proyecto:

index.html: página principal. 
experiencias.html: catálogo de experiencias. 
detalle.html: información específica de una experiencia. 
reservar.html: formulario de solicitud de reservas. 
contacto.html: información de contacto. 
login.html: página de inicio de sesión. 
admin.html: panel visual de administración de experiencias y reservas. 
assets/css/base.css: estilos generales del sitio web.


Alcance del proyecto

El sitio es una maqueta académica con páginas enlazadas, tablas y formularios. No incluye necesariamente autenticación real, almacenamiento persistente ni conexión a una base de datos. Su propósito es aplicar los conocimientos básicos de desarrollo web mediante una estructura sencilla y fácil de mantener.
